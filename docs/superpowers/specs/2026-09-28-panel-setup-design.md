# 网页首次初始化

用户确认管理员和业务参数在面板中配置；监听端口、HTTPS 和 Agent 证书不包含在本次设置范围。

## 流程

安装器自动生成数据库密码、代理加密密钥和独立的 256 位初始化凭证，不询问管理员邮箱、密码或业务参数。服务启动后提示浏览器访问面板，并在安装终端显示一次性初始化凭证。用户在网页填写凭证、管理员邮箱和密码；创建成功后进入登录页，再进入管理页配置资源、倍率、套餐额度和限制、授权与转发策略。现有业务表单复用，不自动创建示例数据。

## 安全与兼容

初始化凭证通过只读挂载的私有文件提供，不通过公开 API、URL、访问日志或 Git 暴露。GET 初始化状态只返回是否需要初始化、入口是否可用。POST 验证凭证、同源请求、请求长度、字段和密码，限制创建请求频率。数据库事务锁保证并发最多创建一个初始管理员；完成标记与管理员及审计在同一事务保存，管理员停用不会重新开启入口。已有管理员通过迁移标记完成，升级保留密码和全部业务数据。预览模式不开放初始化。

## 验证

回归覆盖未初始化、错误凭证、完成后拒绝、无凭证拒绝、跨源拒绝、非法密码、并发和失败回滚。安装器无管理员环境变量即可完成首次部署，重试保留初始化凭证与代理密钥；前端能区分初始化、登录、预览和已登录状态。运行 Go、前端、部署脚本测试与生产构建。公网访问检查与远端更新分别记录，不能用本地测试声称线上发布成功。
