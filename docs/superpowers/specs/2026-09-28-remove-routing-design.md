# 删除分流功能

用户要求删除项目中与分流相关的功能。本次沿既有正式版开发及 GitHub 更新授权完成开发，不执行 VPS 部署或线上数据库操作。

## 范围

- 删除分流策略及规则管理、GeoSite/GeoIP 规则集管理、对应 API、RBAC 权限和 WebUI。
- 删除订阅对分流策略的绑定、导出时的规则加载和格式展开，以及套餐分流规则限额。
- 保留代理连接、服务端线路候选池、多跳转发、订阅 Token 和 Clash/Mihomo/sing-box/Surge 导出。客户端配置使用默认 PROXY 组；各格式必需的最终代理规则仍保留。
- HTTP 创建/修改请求中的旧分流字段按未知字段拒绝，避免客户端以为绑定仍有效。

## 升级

历史迁移 1–27 已发布并校验，保持内容不变。新增迁移 28 删除订阅绑定列、分流相关表、套餐限额列及角色权限；保留订阅本身、Token、代理连接、线路、套餐和其它冻结授权字段。已有冻结快照的旧分流限额由新类型忽略，无需改写计费历史。

升级会清除分流策略、规则和规则集数据。安装器已有迁移前备份流程；回退迁移仅恢复空结构、系统权限和默认限额，恢复分流数据需要升级前数据库备份。

## 验证

先验证旧订阅字段拒绝和前端订阅 payload 回归，再完成 Go、WebUI、脚本、构建和 OpenAPI 检查。数据库迁移应覆盖已有订阅保留、分流结构和权限删除、回退结构恢复；没有真实 PostgreSQL 条件时明确记录未执行的范围。当前产品文档更新，历史设计和发布记录加历史说明。
